# AUREN — Focus Run

A small original endless-runner game built into AUREN.

Open `focus-run.html` to play. It uses a three-lane runner structure inspired by the endless-runner genre, with original AUREN visuals and mechanics.

- three lanes
- keyboard + touch controls
- jumping
- obstacles and focus collectibles
- increasing speed
- score + local best score
- responsive layout
- no external game assets
