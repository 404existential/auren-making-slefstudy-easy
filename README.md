# AUREN — Your education, built around you.

A premium, AI-native academic platform for Indian students.

## Current build

This repository currently contains the first polished frontend foundation:

- editorial/luxury-university visual system
- responsive landing page
- compact hero dashboard preview
- click-to-open feature experiences
- AI Tutor teaser
- Infinite Practice teaser
- AUREN NATIONAL weekly test teaser
- Academic Journal preview
- responsive mobile navigation
- accessible modal interactions

## Product direction

AUREN is designed as an academic operating system rather than a conventional course marketplace. Future phases will connect authentication, Supabase data, AI tutoring, adaptive practice, question generation, exam systems, weekly national tests, study planning, progress analytics, community, student profiles and parent/admin experiences.

## Run

This first phase is static and can be opened directly as `index.html` or deployed with GitHub Pages.
